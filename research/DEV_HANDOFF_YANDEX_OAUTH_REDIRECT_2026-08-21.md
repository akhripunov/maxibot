## Yandex contract and change

The official Yandex OAuth URL-code contract marks `redirect_uri` as optional:
when omitted, Yandex uses the first Web-service Redirect URI registered for the
OAuth application. The token exchange contract does not require
`redirect_uri`, and the existing `exchange_code()` already omits it.

The minimal workaround therefore removes only `redirect_uri` from
`authorize_url()`. `response_type`, `client_id`, `scope`, and `state` remain
unchanged; callback state consumption, code exchange, and token storage are
unchanged.

Updated `.env.example` and production `.env`:

```text
YANDEX_OAUTH_REDIRECT_URI=https://go.maxibot.pro/oauth/yandex/callback
```

No attribution, goals, sender, or OAuth secret was changed.

Production env backup was created as
`.env.backup-yandex-redirect-20260821124323`; it was not read or published.
